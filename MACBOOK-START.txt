FRIDAY DESKTOP — M1 MACBOOK

Safari немесе Chrome қажет емес. Қосымша жеке Mac терезесімен ашылады.
Талаптар: macOS 12+, Python 3.10–3.13 (Python 3.12 ұсынылады).
Python: https://www.python.org/downloads/release/python-31210/
Жергілікті AI: https://ollama.com/download/mac

1. Жаңартылған ZIP архивін ашыңыз.
2. Terminal ішінде жаңа FridayAI-main папкасына өтіп:
   bash start.command
3. Бірінші іске қосуда desktop тәуелділіктері және Ollama моделі жүктеледі.
4. GUI ішінде «Жұмыс папкасын таңдау» басыңыз.
5. Мысалы: «Папкадағы report.pdf файлын оқып, қорытындысын summary.md-ға жаз».
6. Ұсынылған файл өзгерісін тексеріп, «Осы өзгерісті сақтау» басыңыз.
7. «Қолданбаны ашу» батырмасы AI-сыз да орнатылған Mac қолданбасын ашады.
   AI-ға «Calculator аш» сияқты тапсырма да бере аласыз.
8. «Дауыспен айту» басып сөйлеңіз, қайта басқанда дыбыс мәтінге айналып жіберіледі.
   Жергілікті Whisper small моделі бірінші рет интернеттен жүктеледі.
   Mac микрофонға рұқсат сұраса, рұқсат беріңіз.
9. Баптауларда Ollama/OpenAI, модель мен дауыс тілін таңдаңыз.
   API кілті файлға сақталмайды. OpenAI режимінде файл мәтіні мен дыбыс бұлтқа жіберіледі.

Friday.app жасау (осы Mac-та): GUI-ді жапқан соң
   bash make-mac-app.command
Нәтиже: dist/Friday.app. Finder арқылы ашып, Applications ішіне көшіруге болады.
Бұл .app Linux-та жасалмайды; осы M1-дің архитектурасы үшін жергілікті жиналады.

Тарих/баптаулар: ~/Library/Application Support/Friday
Whisper кэші: ~/Library/Caches/Friday/whisper
Тек таңдаған папкаға рұқсат беріледі. Жасырын құпия кілттер оқылмайды.
Файлды жою, кез келген shell командасын орындау, хат жіберу және қолданбалардың
ішкі батырмаларын автоматты басу осы нұсқада қолдау таппайды.
PDF скандары үшін OCR бөлек қажет. DOCX және мәтін/код файлдары оқылады.
Қазақша дыбыстау Mac-тағы дауысқа байланысты; орысша/ағылшынша дауысқа ауысуы мүмкін.
Тіл түсіну сапасы мен жылдамдығы таңдалған модельге байланысты.

Ескі веб-нұсқа керек болса: bash web.command
