FRIDAY AI — MACBOOK

1. ZIP архивін ашыңыз. FridayAI папкасы пайда болады.
2. Python 3.10 немесе одан жаңа нұсқасын орнатыңыз:
   https://www.python.org/downloads/macos/
3. Terminal ашып, папкаға өтіңіз. Мысалы:
   cd ~/Downloads/FridayAI
4. Іске қосыңыз:
   bash start.command
5. Алғашқы іске қосқанда тәуелділіктер интернеттен орнатылады.
   OpenAI API кілтін Terminal ішінде енгізіңіз. Кілт экранда көрсетілмейді,
   файлға сақталмайды, тек осы сеанс үшін қолданылады.
   Кілтсіз интерфейсті ашу үшін Enter басыңыз; AI жауаптары кілтсіз жұмыс істемейді.
6. Браузер автоматты түрде ашылады. Сервер жұмыс істеп тұрғанда Terminal-ды ашық ұстаңыз.
   Тоқтату: Ctrl+C.

Микрофонға браузерде рұқсат беріңіз. Дауыс тануға Chrome немесе Edge ұсынылады.
Қазақша дауыс қолдауы браузер/құрылғыға байланысты.
Әңгімелер мен жазбалар осы браузерде сақталады.
AI хабарламалары OpenAI-ға жіберіледі. API қолдануға баланс/лимит қажет.

Егер 8000 порты бос болмаса:
   PORT=8001 bash start.command

Бұл — веб-қосымша, macOS .app емес. Intel және Apple Silicon құрылғыларында
үйлесімді Python арқылы іске қосылады; нақты MacBook-та тексерілген жоқ.
Архивте API кілттері, .git, ескі Python бинарлары және виртуалды орта жоқ.
